# Snake Game

Acesse o projeto: https://rafaelssant021.github.io/snake-game/

## Sobre
Este projeto é uma recriação do clássico jogo Snake, desenvolvida utilizando HTML, CSS e JavaScript.
O objetivo foi praticar lógica de programação, manipulação do DOM e conceitos fundamentais de desenvolvimento de jogos no navegador.

---

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

---

## Funcionalidades
- Movimentação da cobra com teclado
- Sistema de pontuação
- Crescimento da cobra ao consumir itens
- Detecção de colisão (parede e corpo)
- Reinício automático ao perder

---


## O que eu pratiquei neste projeto
- Lógica de jogo (game loop)
- Manipulação de arrays para controle da cobra
- Detecção de colisões
- Atualização dinâmica da tela
- Controle de eventos do teclado

---

## Como funciona
O jogo é executado em tempo real no navegador, atualizando continuamente a posição da cobra e verificando colisões.

---

## Estrutura do projeto
- index.html → estrutura do jogo
- style.css → estilização
- script.js → lógica do jogo
